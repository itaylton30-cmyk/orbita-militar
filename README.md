# Órbita Militar

Landing page responsiva para uma mentoria de vestibulares militares, com tema espacial, HTML semântico e CSS no mesmo arquivo.

## Como visualizar

Abra `index.html` diretamente no navegador. Não é necessário instalar dependências ou executar uma etapa de build.

## Personalização

- Substitua `55SEUNUMERO` no link do WhatsApp pelo DDI, DDD e número de atendimento, usando somente dígitos.
- Ajuste o nome provisório **Órbita Militar**, os textos e os vestibulares conforme a oferta real da mentoria.
- As cores e os espaçamentos principais estão nas variáveis CSS em `:root`.

## Recursos

- Layout responsivo com Grid e Flexbox.
- Ilustração orbital em SVG, sem imagens externas.
- Botões com transição suave e efeito de brilho.
- Link para pular ao conteúdo, foco visível e suporte a movimento reduzido.

O JavaScript apenas atualiza o ano dos direitos reservados. O contato ocorre pelo link do WhatsApp; não há formulário, backend ou armazenamento de dados.
